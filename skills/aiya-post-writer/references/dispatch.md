# 判类型：载体 × 形态

落笔之前先回答两个独立的问题，不是回答一个问题：

- **载体**：这是什么东西（漫画 / GALGAME / 游戏 / 音声 / 图集 / 书籍 / 都不是）→ 决定字段集、标题第一个方括号、分类候选、情报源。
- **形态**：一个还是多个、首发还是分流 → 决定正文骨架、`resource_other` 里的词、标题前缀。

旧的手选模式把这两轴压成了一张 8 项列表，所以「漫画合集」无处可去。这里拆开。

## 判载体

按可靠性从高到低看三样，**前一样能定就不用看后面**：

| 顺序 | 信号 | 怎么读 |
|---|---|---|
| 1 | 来源域 | dlsite → 音声 / 同人志 / GALGAME；vndb、批评空间、getchu、厂家官网 → GALGAME；steam、epic、gog → 游戏；豆瓣读书、出版社官网、ISBN → 书籍；汉化组发布页、连载杂志页、单行本目录 → 漫画；作者主页、patreon、fantia、booth → 图集 |
| 2 | 结构指纹 | `RJ` 号 → 音声；`(Cxx) [社团 (作者)]` 逐条列举 → 同人志清单；`1-35` / `全 12 卷` + 连载状态 → 漫画或书（有 ISBN 或小说体裁才是书）；`57SET` / `80G` / 张数 / 分辨率 → 图集；`setup.exe` / 免安装 / DLC / 升级档 → 整合包；`シナリオ` / `原画` / `ブランド` → GALGAME |
| 3 | 词法落位 | 必须能落到 `resource_category` 的某个 id 上。落不上就 `other`，不硬猜 |

**用户措辞只是提示**，不能覆盖上面三项。「这个 galgame」而来源是 Steam → 还是按游戏处理，并在回报里说一句。

载体对应的文件、骨架与分类候选：

| 载体 | 读哪份 | 骨架 | 分类候选 |
|---|---|---|---|
| 漫画 / 单行本 / 同人志 | `types/comic.md` | `spec` | 漫画 · 单行本 · 同人志 |
| GALGAME / 视觉小说 | `types/galgame.md` | `quote` | GALGAME |
| 游戏 / 整合包 | `types/game.md` | `spec` | 游戏 |
| 同人音声 / 分轨音频 | `types/voice.md` | `spec`（每作一块） | 同人音声 |
| 图集 / 写真 / COSPLAY / 同人CG集 | `types/gallery.md` | `plain` | 图片集 · 写真集 · COSPLAY · 同人CG集 |
| 书籍 / 轻小说 | `types/book.md` | `quote` | 书籍 · 轻小说 |
| 都不是 / 拿不准 | `types/other.md` | 混合 | 留空或最泛的一个 |

站内还有 `番剧` `里番` `电影` `剧集` `音乐专辑` `播客` 这些分类，目前没有对应模板——按 `other.md` 处理，分类照实挂，并在回报里说明「这类还没有骨架，正文是通用整理」。

## 判形态

| 形态 | 判据 | 骨架 | 标题 | `resource_other` |
|---|---|---|---|---|
| 单部 | 一个作品 | 载体默认骨架 | `[载体] [主体] 名称 体量 [标记]` | 状态与版本词 |
| 系列 / 全卷 | 同一作品的多个部分 | 载体默认骨架 + 可选系列目录 | 体量写 `系列全` / `1-22+1` | 合集 · 完结 |
| 合集（多部不同作品） | 逐条列举，作品之间无续作关系 | `list` | `[合集] [主体] … 合集 [标记]` | 合集 |
| 分流 / 搬运 | 语料自述「转载」「补档」「分流」，或来源不是首发页 | 载体默认骨架 | 前缀 `[分流]` 或 `[搬运]` | 分流 · 搬运 |

`list` 骨架的正文规则见 `writing.md`「四种骨架」；`合集` 与载体不冲突——同人志合集的载体仍是 `同人志`，只是正文变成清单。

## 冲突与提问

**只在下面两种情况停下问人**，其余一律自己判并声明：

1. 来源域与结构指纹指向两个不同载体（DLsite 页面上同时挂了音声和同人CG集，且语料里两者都出现）。
2. 形态无法确定：语料是一串名字，看不出是同一作品的各部分还是不同作品。

问法要具体，给出你的判断和依据：「这批看着像同一社团的三部同人志（RJ 号连号），按合集写还是各写一篇？」

## 声明判定

落笔前一行，写清两轴和依据：

```
按 漫画 / 单行本 · 单部 处理（依据：东立官网书目，卷数 1-35）
```

**不等确认，接着写。** 判定依据必须外显——错载体的代价是整篇结构错（图集塞了 blockquote、合集写成单部规格块），比错标题严重得多；写出来人才能一眼截住。回报时把这一行重复一次。

| 漫画 / 书籍 / GALGAME | 一般不必，官方页够用 | —— |
