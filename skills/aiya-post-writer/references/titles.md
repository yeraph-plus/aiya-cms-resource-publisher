# 标题

标题只有一份定义，就是这里。`types/*.md` 不再各写一遍，只指出本载体的载体词与体量写法。

标题在站内有检索功能：读者靠前缀、体量、版本筛自己要不要点。所以判断标准不是「像不像存量帖」，是**读者能不能从标题判断这部作品是什么、有多少、什么版本**。

## 语法

```
[前缀][前缀] 名称 体量 [尾缀]
```

方括号的个数没有规定，一到三个都行。每个位置承担一种信息，用不用看这部作品有没有那类信息：

| 位置 | 放什么 | 为什么放这 | 例子 |
|---|---|---|---|
| 前缀（第一格） | 形态词（`合集` `完结` `分流` `搬运`）**或**载体词（`GALGAME` `整合包` `模拟器` `漫画` `SLG` `杂志`） | 决定读者第一眼怎么归类。两种都有时写形态词，载体让到第二格——存量 604 个标题里 `[合集]` 212/242、`[搬运]` 15/15、`[分流]` 8/9 都在第一格 | `[合集]` `[GALGAME]` `[完结]` |
| 前缀（第二格起） | 主体：社团 / 作者 / 厂商；也可以是子类型 | 读者按作者追作品 | `[ωstar]` `[北条 司]` `[音声]` `[画集]` `[ADV]` |
| 名称 | 中文译名；没有通行译名就用原文名 | 唯一不可省的字段 | `城市猎人` `千恋＊万花` |
| 体量 | 紧跟名称：卷数、集合数、年代范围、套数+容量 | 判断规模 | `1-35` `全35卷（平装）` `系列全` `1991 - 2023` `35+15SET / 45G` |
| 尾缀 | **语言与形态**：哪家的中文版、什么格式的盘，词从「尾缀写什么」的固定表里挑 | 判断能不能直接看 | `[东立中文版]` `[汉硬]` `[B漫网络版]` `[免安装][简体中文]` |

站内 558 篇里 78% 是「两个前缀 + 一个尾缀」，方括号三个是主流密度。**这是手写时代的常见形状，可参考，不是配额**：前缀凑不满就少写一个（`[整合包] 作品名（原名）[免安装][简体中文]`），信息多就多一个（`[合集][ADV][Yosino] 作品合集（2023）`）。凑前缀来对齐密度，读者多读到的是噪声。

## 常见形状

这些是存量帖的写法，照写读者不会觉得陌生：

```
[完结][北条 司] 城市猎人 / City Hunter 1-35 [东立中文版]
[合集][如月 群真] 汉化本合集
[合集][高苗床 (高苗京鈴)] 妹のおてつだい 汉化合集
[GALGAME][ωstar] 美少女万华镜 系列全 [汉硬合集]
[GALGAME][Yuzu-Soft] 千恋＊万花 [汉硬]
[整合包] 死或生5（Dead Or Alive 5：Last Round）[免安装][简体中文]
[SLG][Loweki] 霓虹闪烁 Neon Effect! 0.1.1 [PC+ANDROID][AI机翻]
[搬运][杂志] 科幻世界 1991 - 2023 杂志PDF合集
[分流][音声] 作品名 [RJ226361]
```

注意 `[合集][…] 汉化本合集` 这类：形态词占第一格，载体让位，「合集」在名称里再出现一次。而 `[漫画][作者] 合集` 这种写法站内很少——同一部合集的读者更关心「合了什么」，不是「属于哪个分类」（分类在词法里）。

## 尾缀写什么

尾缀回答「什么语言、什么形态」，从下面这张表里挑，不自己组词：

| 组 | 固定词 | 什么时候用 |
|---|---|---|
| 语言 | `官中` `简体中文` `繁体中文` `汉化` `机翻` `AI机翻` `生肉` | 读者能不能直接读 |
| 形态 | `硬盘版` `免安装` `安装版` `整合版` `完整版` `试玩版` `DL版` | 拿到的是什么包 |
| 语言 + 形态合并 | `汉硬` `汉硬合集` | 两件事能一句话说完时用，比两个方括号好读 |
| 出版社版本 | `东立中文版` `B漫网络版` `玉皇朝中文版` `天下中文版` `角川中文版` `青文中文版` `尖端中文版` `东贩中文版` `长鸿中文版` | 漫画 / 书籍：哪家的中文版 |

顺序固定「形态 → 语言」：`[硬盘版][官中]`、`[免安装][简体中文]`、`[硬盘版][机翻]`。短写（`简中` `繁中`）与全称（`简体中文` `繁体中文`）都通行，同一批帖里选一种；`官中` 与来源原话 `官方简中` 也都对，同样保持一致。

站内高频词（558 篇实测）作为参考，不构成配额：`汉硬` 108、`东立中文版` 43、`B漫网络版` 36、`玉皇朝中文版` 11、`天下中文版` 10、`东立数位版` 9、`AI机翻` 9、`汉硬合集` 8、`角川中文版` 8、`官方简中` 7、`青文中文版` 4、`尖端中文版` 4、`机翻汉硬` 4、`东贩中文版` 3、`长鸿中文版` 3。

写尾缀时：

- 出版社版本名用**来源里能查到的原话**（`东立中文版`、`B漫网络版`），不自己造；语言与形态从上面的固定表里挑，`汉硬` 这类站内通用简写直接用。
- 内容属性（`全彩` `无码`）进 `resource_other` 词法，不占标题——它们是筛选条件，不是版本标识。
- `[免安装]` `[BDrip]` 这类格式词只在确实决定「能不能直接用」时写（游戏、录像类）。
- 语言能一句话说完就不拆两个方括号：`[汉硬]` 比 `[简体中文][汉化硬盘版]` 好读。

## 名称里的并列与括号

两种写法并存，按关系选，不是按风格选：

| 关系 | 写法 | 实例 |
|---|---|---|
| 两个名字平等并列（中译与原名都是正式名） | ` / ` | `城市猎人 / City Hunter`、`中华小厨师 / 中华一番` |
| 括号里是补充信息（原名、版本、平台、模拟器） | `（）` | `死或生5（Dead Or Alive 5：Last Round）`、`塞尔达传说：旷野之息 终极整合（Cemu模拟器V1.26）` |

`/` 在名称位是并列符，在体量位是分隔符：`[35+15SET / 45G]`（套数 / 容量）。两处不要混。

括号里装**版本、平台、模拟器**这类补充信息比塞尾缀自然——尾缀只留给语言与格式。

## 正例与负例

| 写法 | 判断 |
|---|---|
| `[合集][高苗床 (高苗京鈴)] 妹のおてつだい 汉化合集` | 对：形态 + 社团（含作者）+ 名称 + 汉化标记 |
| `[完结][北条 司] 城市猎人 / City Hunter 1-35 [东立中文版]` | 对：形态 + 作者 + 中英并列 + 卷数 + 版本 |
| `[漫画][北条 司] 城市猎人 1-35 [东立中文版]` | 可以：载体占第一格，形态缺失。同族帖多用 `[完结]`，因为「已完结 + 中文版」是读者最关心的筛选条件 |
| `[分流][音声][社团] 作品名 RJ123 [汉化]` | 冗余：形态与载体已经说完，社团在第三格读者不会去读；且四个方括号挤掉了名称的位置 |
| `[合集] 城市猎人 1-35` | 缺主体与尾缀，读者筛不到版本 |
| `千恋＊万花 汉化硬盘版 神作必玩！！！` | 无前缀无尾缀，营销词与感叹号挤占了检索位 |
| `[GALGAME][Yuzu-Soft] 千恋＊万花 2024年最新版 [汉硬]` | 「最新版」会立刻过期；版本差异写进正文，标题只写版本标识 |
| `[图片集][作者] 套图合集 [80G]` | 体量只给容量不给套数，读者无法判断规模 |

## 名称与数字的来源

- 名称用**通行中文译名**；没有通行译名就直接用原文名，不做音译。
- 体量里每个数字都要能指到来源（官方书目、商店页的卷数、目录里的文件数）。查不到就整个体量不写，不留 `1-?`。
- 名称里的符号原样保留：`＊`、`：`、`・`、`！`、英文大小写、`RJ` 号。`[Hamao]`、`[CHOCO]` 这类外文社名不翻译。
