# GALGAME / 视觉小说

## 识别

正向：来源是 DLsite、Getchu、VNDB、批评空间、厂家官网（ωstar、Yuzu-Soft、Key、ILLUSION…）；语料里出现 `シナリオ` / `原画` / `ブランド` / `攻略`；作品以「读」为主、有分支或多结局。

排除：

- 有玩法的 RPG / SLG / 动作，即便同在一个商店页 → `game.md`。
- 只有音频没有画面 → `voice.md`。
- 全年龄乙女向仍是 GALGAME，只是 `resource_other` 加 `乙女向`。

## 采信数据源

搜索词怎么构造（编号优先、原文名 + 站点名、落页三条判据）见 `references/verify.md`「怎么找到那几个站」。下表按顺序试，命中即停。

| # | 搜索词 | 落在哪 | 能定什么 |
|---|---|---|---|
| 1 | `原文名 公式` | 厂家官网作品页 | 发售日、原题、品牌、规格、价格 |
| 2 | `原文名 dlsite` / `原文名 getchu` / `原文名 fanza` | 商店页 | 发售日、品牌、官方简介、年龄指定、文件形式 |
| 3 | `原文名 vndb` | VNDB | 别名、系列关系、开发商、发行日期（日 / 英）、关联作 |
| 4 | `原文名 批評空間` | 批评空间「基本情报」页 | 发卖日、品牌、原画、脚本、时长 |

采信边界：

- 商店页简介先删促销话术再抄（`今だけ50%OFF`、`レビュー高評価`），正文不出现这些。
- 批评空间看「基本情报」页，不看评分与评论正文——那是读者判断。
- 攻略站、汉化组说明、视频简介只当线索：里面写的原题与社团回第 1、2 行复核，复核不到就不写。

## 标题

载体词用 `GALGAME`。`汉硬` 是站内习惯写法（汉化硬盘版），优先于「汉化版整合硬盘版」；系列全作写 `系列全`，只覆盖一部分写实际范围 `1-3`。语法见 `references/titles.md`。

## 正文

字段少、叙述多：封面 → 官方简介 → 分区线 → 说明段落 →（可选）系列目录。

```
<img src="file:///…" alt="封面" />

<blockquote>官方剧情简介。照抄商店页或官网，第三人称，1–2 段，去掉促销话术。</blockquote>

<hr />

版本与系列说明：是否汉化硬盘版、含不含补丁、DLC 情况。语料有据才写，没有就整段删。

系列目录：

<ul><li>作品名（日文原名 / 中文译名）</li></ul>

[alert type="info" name="运行提示"]汉硬版需要转区运行；补丁会被安全软件误报，加白名单后再启动。[/alert]

[internal]来源：https://www.dlsite.com/…/RJ0123456.html（发售日、原题、社团）／VNDB v12345（系列关系）[/internal]
```

`<blockquote>` 在这里只装**官方简介**，不装字段——GALGAME 没有固定字段集，规格写在说明段落里。

系列目录是可选块：只在语料确实列出多作时写，按原作顺序排，不混入评价。


## 分类

| 词法 | 填什么 |
|---|---|
| `resource_category` | `GALGAME`，1 个就够 |
| `resource_other` | 硬盘版 · 机翻 · 官方中文 · 合集 · 完结。AI 汉化与机翻区别写进正文，词法只挂机翻 |
| `resource_author` | 社团 / 品牌名（`ωstar`、`Yuzu-Soft`） |
| `resource_content` | 题材 0–6 个 |
| `resource_original` / `resource_character` | 改编作或角色名明确时才填 |

注意 `resource_author` 填的是**制作方**，不是脚本家或原画师个人；有明确署名作者且站内有这个词时才另加。
