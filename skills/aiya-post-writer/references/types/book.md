# 书籍 / 轻小说

## 识别

正向：来源是出版社官网、ISBN 查询、豆瓣读书、作者主页；语料里有 ISBN、译者、出版年、卷数、`既刊`；体裁是小说或散文。

排除：

- 有分镜和画格的漫画 → `comic.md`（有 ISBN 的漫画单行本按漫画处理）。
- 设定集、画集 → `gallery.md`。

漫画与书籍最容易混：判断依据是**体裁**，不是有没有 ISBN。有 ISBN 的漫画单行本仍归漫画。

## 采信数据源

搜索词怎么构造（编号优先、原文名 + 站点名、落页三条判据）见 `references/verify.md`「怎么找到那几个站」。下表按顺序试，命中即停。

| # | 搜索词 | 落在哪 | 能定什么 |
|---|---|---|---|
| 1 | `作品名 ISBN` | 出版社书目 / 国立国会図書館サーチ / openBD | ISBN、出版社、出版年、页数 |
| 2 | `作品名 出版社名 既刊` | 出版社官方书目页 | 卷数、完结与否、连载状态、出版年 |
| 3 | `原文名 openbd` 或直接查 `openbd.jp` | openBD | 出版信息、封面、译者（日文版） |
| 4 | `中文名 豆瓣` | 豆瓣读书 | 中文译名、中文版出版社、译者、简介 |

采信边界：

- 第三方电商页（Amazon、京东、淘宝）的价格与发售日常年不动却已过期，还有预售占位；只当线索。
- 评分与书评是读者判断，不进正文也不进字段。
- 网文站的作品简介不是出版社文案，跟这套字段无关。
- 卷数以出版社书目为准；豆瓣与电商显示的是「当前在售」，不等于「全书共几卷」。

## 标题

载体词用 `书籍`——轻小说也归这一类，站内没有 `轻小说` 这个分类词，标题与词法都用 `书籍`。单卷不写体量；译者不进标题，写进正文。语法见 `references/titles.md`。

## 正文

书籍与 GALGAME 同族：一段引来的简介、分区线、一段出版信息叙述。

```
<img src="file:///…" alt="封面" />

<blockquote>官方简介。照抄出版社或官方页，不改写剧情。</blockquote>

<hr />

出版信息一段：作者、出版社、卷数、完结与否、译本与译者、出版年份。只写语料有据的内容。

[internal]来源：出版社官网书目（卷数、出版年、译者、ISBN）／豆瓣读书（中文译名、简介）[/internal]
```

出版信息**写成一段话**最自然：作者、出版社、卷数、译者这些串成句子读起来比列表顺，书籍帖在站内也多是这个形状。条目超过六七项、或帖子本身是书目清单时，改字段块更好查。


## 分类

| 词法 | 填什么 |
|---|---|
| `resource_category` | `书籍`（轻小说同样挂这个，站内没有单独的轻小说分类） |
| `resource_other` | 完结 · 连载 · 官方中文 |
| `resource_author` | 作者名。译者不进这一列 |
| `resource_content` | 题材 0–6 个 |
| `resource_original` / `resource_character` | **留空**：书籍类基本不适用，不要硬填改编源 |
