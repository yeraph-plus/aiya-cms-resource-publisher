# 书籍 / 轻小说

## 识别

正向：来源是出版社官网、ISBN 查询、豆瓣读书、作者主页；语料里有 ISBN、译者、出版年、卷数、`既刊`；体裁是小说或散文。

排除：

- 有分镜和画格的漫画 → `comic.md`（有 ISBN 的漫画单行本按漫画处理）。
- 设定集、画集 → `gallery.md`。

漫画与书籍最容易混：判断依据是**体裁**，不是有没有 ISBN。有 ISBN 的漫画单行本仍归漫画。

## 情报源

1. 出版社官网 / 官方书目——卷数、出版年、译者、ISBN 以它为准。
2. ISBN 查询（国家图书馆、openBD）——补出版信息。
3. 豆瓣读书——只补「简介」与中文译名，评分和书评不要碰。

## 标题

```
[书籍] [作者] 作品名 卷数范围 [标记]
```

- `[书籍]` 或 `[轻小说]`，按体裁选，别两个都写。
- 译者不进标题；译本信息写在正文里。

## 正文

骨架 `quote`。

```html
<img src="file:///…" alt="封面" />
<blockquote>官方简介。照抄出版社或官方页，不改写剧情。</blockquote>
<hr />
<p>出版信息一段：作者、出版社、卷数、完结与否、译本与译者、出版年份。只写语料有据的内容。</p>
```

出版信息**写成一段话**，不要拆成字段块——书籍帖在站内就是一段，字段块是游戏和漫画的形状。

## 分类

| 词法 | 填什么 |
|---|---|
| `resource_category` | `书籍` / `轻小说` |
| `resource_other` | 完结 · 连载 · 官方中文 |
| `resource_author` | 作者名。译者不进这一列 |
| `resource_content` | 题材 0–6 个 |
| `resource_original` / `resource_character` | **留空**：书籍类基本不适用，不要硬填改编源 |
