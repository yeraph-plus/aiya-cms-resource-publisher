# 漫画 / 单行本 / 同人志

## 识别

正向：有卷数或册数（`1-35`、`全 12 卷`）、连载状态；来源是连载杂志页、单行本目录、汉化组发布页、漫画数据库；语料里出现「作者 / 出版社 / 连载」。

排除：

- 逐条列举多部、彼此无续作关系 → 形态是合集，正文换成目录型，载体仍按这条判（`writing.md`「怎么组合」）。
- 没有剧情连载、主要是画集或套图 → `gallery.md`。
- 有 ISBN 或明显是小说体裁 → `book.md`。

三个分类怎么分：正规出版连载印成单行本 → `单行本`；社团自印、同人展售卖 → `同人志`；不好归的漫画形态 → `漫画`。别三个全挂，最多两个。

## 采信数据源

搜索词怎么构造（编号优先、原文名 + 站点名、落页三条判据）见 `references/verify.md`「怎么找到那几个站」。下表按顺序试，命中即停。

| # | 搜索词 | 落在哪 | 能定什么 |
|---|---|---|---|
| 1 | `原文名 単行本 出版社名`（出版社不知道就省掉最后一格） | 出版社官网书目页 | 卷数、出版社、原出版社、ISBN、连载状态 |
| 2 | `原文名 dlsite` 或 `原文名 とらのあな` | 同人志商店页 | 发行日、社团、页数、文件形式（同人志走这一行，跳过第 1 行） |
| 3 | `原文名 mangaupdates` | Baka-Updates | 别名、原版名称、作者、连载起止年 |
| 4 | `原文名 マンガペディア` | マンガペディア | 连载杂志、出版社（与第 1 行交叉验证） |
| 5 | `中文名 豆瓣` | 豆瓣读书 | 中文译名、中文版出版社、译者 |

采信边界：

- 卷数与连载状态只认出版社页。二手数据库的卷数常停在上一次更新，只用来补别名。
- 汉化组发布页不是官方页：只取「汉化组 / 语言 / 版本标记」三项，卷数、状态不从这里抄。
- 漫画资源站、聚合目录站、贴吧帖只当线索，哪怕它是搜索结果第一条。官方页没有的字段不写。

## 标题

载体词用 `漫画`，正规出版用 `单行本`。体量写卷数，尾缀写语言与版本。语法与其他位置的填法见 `references/titles.md`。

## 正文

字段型：封面下来是分区线，然后按内容分节。字段齐就一节装字段、一节装简介，字段少就只留简介。下面是这个组合的写法，不是唯一写法——`writing.md` 的工具箱里还有别的零件可用。

```
<img src="file:///…" alt="封面" />

<hr />

<h3>书籍信息</h3>

<blockquote>中文名称：城市猎人
别名：侠探寒羽良、City Hunter
出版社：东立出版社
册数：全35卷（平装）
原版名称：シティーハンター
原出版社：集英社（JUMP COMICS）</blockquote>

<h3>一些简介</h3>

剧情讲述了未来都市中，冴羽獠以私家侦探身份接活、并在灰色地带伸张正义的故事。

<h3>归档说明</h3>

东立中文版扫图，300dpi，未裁边。

[internal]来源：东立官网书目（卷数、出版社、连载状态）／汉化组发布页（汉化组、版本标记）[/internal]
```

字段只从这九个里挑，缺的整行删：`中文名称 / 别名 / 原版名称 / 作者 / 出版社 / 原出版社 / 册数 / 连载状态 / 汉化组`。

字段与叙述分开装：字段进 `<blockquote>`，剧情评述进段落。字段少于四五项时不必立 `书籍信息` 这一节，直接把段落放在 `<hr />` 之后——站内单部帖有三分之一是这种短形态，可参考。

字段块用 `<blockquote>` 或 `[col_list]` 都行，同一帖不混用（取舍见 `writing.md`「字段块两种形式」）。警示与来源备注照 `references/shortcodes.md`。


## 分类

| 词法 | 填什么 |
|---|---|
| `resource_category` | `单行本` / `同人志` / `漫画`，1–2 个，**用 id** |
| `resource_other` | 完结 · 连载 · 官方中文 · 全彩 · 无码 |
| `resource_author` | 作者名。出版社不进这一列 |
| `resource_content` | 题材 0–6 个 |
| `resource_original` / `resource_character` | 改编作或明确围绕某角色时才填 |
