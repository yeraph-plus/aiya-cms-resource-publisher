# 漫画 / 单行本 / 同人志

## 识别

正向：有卷数或册数（`1-35`、`全 12 卷`）、连载状态；来源是连载杂志页、单行本目录、汉化组发布页、漫画数据库；语料里出现「作者 / 出版社 / 连载」。

排除：

- 逐条列举多部、彼此无续作关系 → 形态是合集，骨架换 `list`，载体仍按这条判（`writing.md` 四种骨架）。
- 没有剧情连载、主要是画集或套图 → `gallery.md`。
- 有 ISBN 或明显是小说体裁 → `book.md`。

三个分类怎么分：正规出版连载印成单行本 → `单行本`；社团自印、同人展售卖 → `同人志`；不好归的漫画形态 → `漫画`。别三个全挂，最多两个。

## 情报源

1. 出版社官网 / 官方书目页——卷数、出版社、原出版社、连载状态以它为准。
2. 汉化组发布页——汉化组、语言、版本标记。
3. 漫画数据库（Baka-Updates、マンガペディア）——只补别名与原版名称。

官方页没有的字段不写。二手 wiki 只用来补「别名 / 原版名称」，不用来补卷数和状态。

## 标题

```
[漫画] [作者] 作品名（原文名）卷数 [版本·语言标记]
```

- 第一个方括号 `[漫画]`，正规出版可用 `[单行本]`。
- 卷数紧跟名称：`1-35`、`全 12 卷`、`1-22+1`（外传单独写清）。
- 尾缀写语言与版本：`[东立中文版]` `[汉化]` `[官方繁中]` `[全彩]`。
- 完结 / 连载属于形态词，可占第一个方括号（`[完结][北条 司] 城市猎人 / City Hunter 1-35 [东立中文版]`）。

## 正文

骨架 `spec`。封面第一张，然后是字段块。

```html
<img src="file:///…" alt="封面" />
<blockquote>中文名称：…
原版名称：…
作者：…
出版社：…
册数：…
连载状态：…
汉化组：…</blockquote>
<hr />
<p>连载历史、剧情概述。官方文案照抄，不改写剧情。</p>
<h3>归档文件</h3>
<p>扫图来源、裁边与否、是否 DL 版。语料有据才写，没有就整块删掉。</p>
```

字段只从这九个里挑，缺的整行删：`中文名称 / 别名 / 原版名称 / 作者 / 出版社 / 原出版社 / 册数 / 连载状态 / 汉化组`。

**不写短代码。** `[col_list]` 在站内存量漫画里很常见（878 篇正文里 160 篇用了它），但本技能统一用 `<blockquote>`：短代码 `preview` 校验不了，写错了要到站点才看得见。

## 分类

| 词法 | 填什么 |
|---|---|
| `resource_category` | `单行本` / `同人志` / `漫画`，1–2 个，**用 id** |
| `resource_other` | 完结 · 连载 · 官方中文 · 全彩 · 无修正 |
| `resource_author` | 作者名。出版社不进这一列 |
| `resource_content` | 题材 0–6 个 |
| `resource_original` / `resource_character` | 改编作或明确围绕某角色时才填 |
