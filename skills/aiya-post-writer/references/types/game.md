# 游戏整合包

## 识别

正向：来源是 Steam、Epic、GOG、厂家官网、整合包说明页；语料里有「免安装」「硬盘版」「已集成」「升级档」「DLC」「解压即玩」；目录里出现 `setup.exe`、`Binaries`、`_CommonRedist`。

排除：

- 以阅读为主、有分支剧情 → `galgame.md`。
- 主机 ROM + 模拟器 → 仍是 `other.md`（站内没有对应分类，不硬挂「游戏」）。

## 情报源

1. Steam / 官方商店页——八个字段里的大部分从这里抄。
2. 厂家官网——发行公司、语言支持以它为准。
3. 整合包说明页——只取证「包含什么 / 已集成什么」，这是整合方的话，不是官方话，别混进官方字段块。

## 标题

```
[整合包] [厂商] 游戏名（英文名）[免安装][语言标记]
```

- `[免安装]` 只在确实免安装时写；带安装器就写 `[安装版]`。
- 英文名与中文名并列时用 ` / `。

## 正文

骨架 `spec`。八个字段一字不改，缺的整行删。

```html
<img src="file:///…" alt="封面" />
<blockquote>游戏名称：…
英文名称：…
游戏类型：…
制作公司：…
发行公司：…
游戏平台：…
语言版本：…
发售日期：…</blockquote>
<hr />
<p>整合包说明：</p>
<ul>
<li>包含…（DLC、升级档）</li>
<li>已集成…（补丁、语言文件、工具）</li>
</ul>
<p>使用说明：解压顺序、启动方式、注意事项。语料有据才写。</p>
```

字段块里**只放官方事实**；整合方加的东西（已集成汉化、附带修改器）写在下面的 `<ul>` 里，两者不要混。

## 分类

| 词法 | 填什么 |
|---|---|
| `resource_category` | `游戏` |
| `resource_other` | 硬盘版 · 免安装 · 官方中文 · 机翻 |
| `resource_author` | 制作或发行厂商名。整合者不是作者，不要填 |
| `resource_content` | 题材 0–6 个（动作、RPG、模拟…） |
| `resource_original` / `resource_character` | 改编自影视 / 动漫时才填 |
